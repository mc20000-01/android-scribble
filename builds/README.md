# Builds

This folder is where local Android Scribble APK artifacts are generated. APK binaries are intentionally ignored by Git because the PR system does not support binary files.

## Generated artifacts

Run `scripts/build_android_artifacts.sh` from the repository root. When successful, it writes:

- `android-scribble-android13-15-debug.apk` - installable debug APK signed with the default Android debug key.
- `android-scribble-android13-15-debug.apk.sha256` - SHA-256 checksum for the debug APK.
- `android-scribble-android13-15-release-unsigned.apk` - release-mode APK generated by Gradle, but not signed for distribution.
- `android-scribble-android13-15-release-unsigned.apk.sha256` - SHA-256 checksum for the unsigned release APK.

The `android13-15` label means the same universal APK is expected to support Android 13, Android 14, and Android 15. The app itself has a lower `minSdk`, so it may also install on older supported Android versions.

## Keeping old builds

Keep only the newest generated build artifacts in this folder. When replacing an APK, move the previous file and its checksum into `builds/old/` and label it clearly with the date or version.

The build script does this automatically before copying fresh APKs into this folder.

Example:

```text
builds/old/android-scribble-android13-15-debug-2026-05-12.apk
builds/old/android-scribble-android13-15-debug-2026-05-12.apk.sha256
```

Please do not let old builds sit beside the latest artifacts in this directory.

## Rebuilding

From the repository root:

```bash
scripts/build_android_artifacts.sh
```

Manual equivalent:

```bash
gradle assembleDebug
gradle assembleRelease
cp app/build/outputs/apk/debug/app-debug.apk builds/android-scribble-android13-15-debug.apk
cp app/build/outputs/apk/release/app-release-unsigned.apk builds/android-scribble-android13-15-release-unsigned.apk
sha256sum builds/android-scribble-android13-15-debug.apk > builds/android-scribble-android13-15-debug.apk.sha256
sha256sum builds/android-scribble-android13-15-release-unsigned.apk > builds/android-scribble-android13-15-release-unsigned.apk.sha256
```
